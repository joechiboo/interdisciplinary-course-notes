## 課堂簡報重點摘要

### 市場分析（3份簡報）

#### 單元一：作戰前的準備工作
- **孫子兵法五大層面**：道、天、地、將、法
- **對應企業商戰**：
  | 兵法 | 企業應用 |
  |-----|---------|
  | 道（民心所向）| 顧客需求、品牌理念、故事 |
  | 天（天時）| 市場大環境、產業趨勢 |
  | 地（地利）| 實體資源 |
  | 將（將領）| 團隊組成/專長 |
  | 法（制度）| 管理方法 |

#### 單元二：市場規模估算
- **市場規模估算三部曲**：
  1. Step 1：找出主要客群（功能型/社交型/情感型顧客）
  2. Step 2：建立市場區隔（確認市場主要變因、找到早期使用者）
  3. Step 3：估算市場規模（顧客人數、預估總產值）

- **TAM / SAM / SOM 原則**：
  | 指標 | 說明 |
  |-----|------|
  | TAM (Total Addressable Market) | 產品或服務的整體潛在市場，最大規模 |
  | SAM (Service Addressable Market) | 你的產品或服務「目前」可觸及的最大市場 |
  | SOM (Serviceable Obtainable Market) | 僅靠你手邊資源，目前產品服務可觸及的市場 |

#### 單元三：波特五力分析
- **五種競爭力**：
  1. 現有競爭者的威脅
  2. 下游需求者的議價能力
  3. 上游供應商的議價能力
  4. 替代品的威脅
  5. 潛在進入者的威脅

- **重點問題**：
  - 現有競爭者有誰？商業模式是什麼？
  - 顧客對產品/服務的需求強度？
  - 供應商的產業集中度、差異性？
  - 替代品功能與顧客需求的匹配度？
  - 現有企業的競爭門檻？

#### 單元四：波特五力應用範例（按摩槍）
- **案例**：Healbo 亞洲第一的運動肌肉按摩槍
- **市場區隔條件**：運動類別、使用情境、年齡、收入水平
- **五力分析結論**：
  - 供應商議價能力：低（模具廠競爭激烈）
  - 潛在進入者威脅：低（國外廠牌進入成本高）
  - 現有競爭者：低（新創產品，競爭者不多）
  - 購買者議價能力：中（健身房/教練訂貨量較高）
  - 替代品威脅：低（現有替代品無法取代產品功能）

#### 單元五：SWOT 分析
| | 正向 | 負向 |
|---|-----|-----|
| **內部** | (S) 優勢：核心競爭力、關鍵資源 | (W) 弱點：最不擅長的業務、缺少的資源 |
| **外部** | (O) 機會：市場缺口、市場趨勢、政策風向 | (T) 威脅：市場萎縮訊號、競爭對手策略 |

### 數位行銷工具百寶箱（4份簡報）

#### 銷售管道
- **線下**：實體商店
- **線上**：線上商城（momo、蝦皮等）

#### 實體店 vs 線上商城的銷售流程
- **實體店**：曝光 → 吸引 → 體驗 → 成交
- **線上商城**：曝光 → 吸引 → 登陸頁面 → 跨平台整合 → 體驗/成交 → 再行銷/推介

#### 數位行銷六階段重點

| 階段 | 重點 | 說明 |
|-----|-----|------|
| 1. 曝光 | 讓顧客能看到這檔產品 | 鎖定客群、選擇平台、依據平台規範完成資訊 |
| 2. 吸引 | 讓顧客願意點擊細看產品 | 商品照片、影片、商品簡介 |
| 3. 登陸頁面 | 讓顧客能看到更多細節 | 頁面操作便利性、他人經驗分享、競品比較 |
| 4. 跨平台整合 | 比較不同管道的曝光加分 | 分享影片、KOL/使用者分享、其他管道曝光 |
| 5. 體驗/成交 | 讓顧客購買產品 | 試用、簡易的付款取貨流程 |
| 6. 再行銷 | 好的產品使用體驗 | 持續互動、鼓勵推薦、銷售其他相關產品 |

## 建議簡報架構

基於課堂內容與作業素材，建議期末簡報採用以下架構：

### 簡報大綱（5-8分鐘版本）

1. **開場故事**（1分鐘）
   - 運用數位敘事技巧，以故事引入產品需求
   - 痛點描述：孩童數位健康的現況問題

2. **產品介紹**（1分鐘）
   - 產品名稱、核心功能
   - 價值主張（解決什麼問題）

3. **市場分析**（1.5分鐘）
   - 目標客層（家長、學校、教育機構）
   - 市場規模（TAM/SAM/SOM）
   - 競爭分析（五力分析簡化版）

4. **商業模式**（1分鐘）
   - 商業模式畫布重點呈現
   - 收益模式

5. **數位行銷策略**（1.5分鐘）
   - 行銷通路選擇
   - 數位行銷六階段規劃
   - 社群經營策略

6. **總結與呼籲行動**（1分鐘）
   - SWOT 總結
   - 未來展望
   - Call to Action
